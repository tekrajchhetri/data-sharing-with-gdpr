# Chapter 2: Foundations of GDPR

## Overview
This directory contains the resources and supplementary materials for **Chapter 2: Foundations of GDPR**.

## Contents

### `data_analysis`
Contains data analysis resources related to GDPR enforcement actions, including statistics and insights on GDPR penalties and fines.

### `html_page`
Contains an interactive HTML page that provides:
- An overview of the core GDPR principles.
- A visual mind map illustrating key GDPR concepts and their relationships.
